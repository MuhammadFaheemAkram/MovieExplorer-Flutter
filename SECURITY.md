# Security Policy

## Supported Versions

MovieExplorer is a learning/reference project. Security fixes are applied to the latest `main` only.

| Version | Supported |
|---------|:---------:|
| `main`  | ✅ |

## Reporting a Vulnerability

Please **do not** open a public issue for security problems.

Instead, email **muhammadfaheem004@gmail.com** with:

- a description of the issue and its impact;
- steps to reproduce (a proof of concept if possible);
- any suggested remediation.

You can expect an acknowledgement within a few business days.

The app has **no backend, no API keys, no accounts and only bundled demo data**. Its only local data is a favorites database and two preferences, so the practical attack surface is small. Reports about unsafe patterns, dependency issues or data-handling concerns are still very welcome.
